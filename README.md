# Daily Big Idea

A growing archive of short, visual essays about ideas that help explain the world.

## Website
Once GitHub Pages is enabled, the site will be available at:
https://happyrabbit29.github.io/daily-big-idea/

## Structure
- `index.html` — permanent homepage and archive
- `editions/` — one standalone HTML file per edition

Each edition is self-contained and includes its own CSS. To publish a new edition, add its HTML file under `editions/`, then add a matching card to `index.html`.

## Publishing
This repository is intended for GitHub Pages. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
